COMPLEX UNFAMILIAR

Generated CU Scenario Lab

Each scenario is one coherent unfamiliar engineering system. All numerical values are generated from a seed, so students normally receive fresh numbers but a teacher can reproduce exactly the same attempt later.

Difficulty: Standard names more intermediate quantities; Hard reduces the scaffolding; Brutal gives minimal guidance about the calculation pathway. The physics and generated system remain valid at every level.
