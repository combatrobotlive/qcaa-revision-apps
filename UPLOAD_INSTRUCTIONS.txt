This patch assumes the main QCAA website is already online.

3. Upload every file in this patch to the repository root.
4. Allow index.html and the interstate app files to overwrite their existing copies.
5. Commit with a message such as: Add Engineering Around Australia comparison hub
6. GitHub Pages will redeploy automatically.
